# Weather App
A simple weather application built with HTML, CSS, and JavaScript. 
It fetches real-time weather data using the OpenWeather API.
## Features
- Search weather by city name
- Shows temperature, description, humidity, wind speed, feels like
- Displays weather icons
- Dynamic background changes based on weather condition
## How to Run
1. Clone the repository
2. Open index.html in browser (use Live Server for best results)
3. Enter city name and click "Get Weather"
